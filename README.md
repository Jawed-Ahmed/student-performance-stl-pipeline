
# Student Performance ETL Pipeline

## Project Overview
This project demonstrates an ETL (Extract, Transform, Load) workflow using a synthetic student performance dataset. Python and Pandas are used to process and clean the data, and the cleaned dataset is imported into MySQL Workbench for database storage and querying.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- CSV
- MySQL Workbench

## Project Workflow
1. **Extract:** Read the original synthetic student performance dataset from a CSV file.
2. **Transform:** Clean and preprocess the data using Python and Pandas.
3. **Load:** Export the cleaned dataset to a CSV file and manually import it into MySQL Workbench.

## Project Files
- **Uncleaned CSV:** Original synthetic dataset.
- **Cleaned CSV:** Dataset after data cleaning and preprocessing.
- **Jupyter Notebook:** Code used to process and clean the data.

## Dataset
The dataset contains synthetic student performance data generated for demonstration purposes and does not represent actual student records.
